# git-commit-gitflow-ko

Git Flow 브랜치 전략과 한국어 커밋 메시지 규칙을 안내하는 Cursor Agent Skill.

## 설치

```bash
# 이 스킬만 설치
npx skills add https://github.com/wwwshe/skills/tree/main/git-commit-gitflow-ko

# 전체 스킬 한 번에 설치
npx skills add wwwshe/skills
```

## 사용법

커밋·브랜치 작업 시 자연어로 요청하거나 스킬을 명시한다.

```
feature 브랜치 만들어서 작업해줘
커밋 메시지 작성해줘
Git Flow로 hotfix 브랜치 어떻게 써?
```
